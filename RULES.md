# Mandatory project rules

- No FastAPI, Python AI backend, Redux Toolkit, or microservices.
- Use React Context API and Bootstrap 5.
- Use Spring AI in Spring Boot with Ollama initially; chat provider must be configurable for OpenRouter later.
- MySQL is authoritative; ChromaDB contains policy embeddings only.
- An LLM never approves/rejects leave and never supplies trusted employee identity or role.
- Back-end authorization is mandatory. Never trust frontend or LLM identifiers.
- Never hardcode credentials, employee records, or dashboard statistics.
- Every button must map to implemented behavior or be absent.
- Test completed features. Do not commit secrets or private employee data.
